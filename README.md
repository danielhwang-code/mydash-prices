# mydash-prices (public)

개인 대시보드의 **공개 시장 데이터**만 담는 저장소. 공개인 것이 의도된 설계다.

여기에는 공개 시세와 종목코드 목록만 들어간다. 보유 수량·매수단가·평가액 같은 개인 금융 정보는 들어오지 않는다. 그 정보는 별도 비공개 저장소에만 있고, 평가 계산은 브라우저에서 한다.

## 파일

| 파일 | 쓰는 주체 | 내용 |
|---|---|---|
| `tickers.txt` | GitHub Actions (비공개 레포에서) | `MARKET,TICKER` 한 줄씩 |
| `data/prices.json` | VPS 크론 | 종목별 최신 종가 + 환율 |

## 왜 공개인가

VPS에 두는 토큰의 권한 범위를 이 저장소 하나로 묶기 위해서다. VPS가 통째로 털려도 나오는 것은 공개 시장 데이터뿐이다.

## prices.json 형식

```json
{
  "updated_at": "2026-09-09T07:00:00+09:00",
  "quotes": {
    "US:AAPL":   {"close": 178.4, "date": "2026-09-08", "stale_days": 0},
    "KR:005930": {"close": 71200, "date": "2026-09-08", "stale_days": 0}
  },
  "fx": {
    "USDKRW": {"rate": 1385.2, "date": "2026-09-08"}
  }
}
```
